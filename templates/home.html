Granted Admin Dashboard

Watch how teachers use Granted. Analytics exclude pilot teachers; Pilot pages show one cohort at a time.

Analytics

Regular teachers only.

  • Features — phonics, vocab, and custom DOK.
  • Usage — signups, activity, edits, funnel, and returns.

Survey

  • Survey Maker — baseline, follow-up, or standalone.
  • Feedback Review — ratings and comments.
  • Survey Results — answers by question.

Monitoring

  • Audit Log — recent events and which types fail.

Pilot

One pilot at a time, except the calendar.

  • Calendar — windows, status, and teacher counts.
  • Pilot Maker — create or edit a window.
  • Pilot Features — feature use for one cohort.
  • Pilot Usage — usage plus grade and subject mix.

Testing

Generate, update, email, and database checks against the live app.

  • Load — a steady class-sized crowd.
  • Stress — keep adding users until something gives.
  • Spike — quiet, then a sudden rush.
  • Custom — set the users and minutes yourself.
