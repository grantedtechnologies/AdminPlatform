Granted Admin Dashboard

This dashboard is for watching how teachers use Granted: the AI reading-worksheet app. Analytics pages exclude teachers who are on a pilot. Pilot pages look at one pilot at a time.

Analytics

Regular (non-pilot) teachers only.

Features

Phonics, vocab lists, and custom DOK over time, plus how many teachers have tried each one. Answers: are teachers using the options we built?

Usage

Worksheets, signups, active teachers, approximate time in the app, edits, the core funnel, and return visits. Answers: are teachers coming back and finishing the loop?

Pilot

One pilot at a time, except the calendar which shows every window.

Calendar

When each pilot starts and ends, and how many teachers are in it. Answers: which windows are live, upcoming, or over?

Pilot Maker

Create or edit a pilot name, school, code, and dates. Answers: can we stand up or correct a window without touching the database by hand?

Pilot Features

The same feature charts as Analytics, filtered to one pilot. Answers: is this cohort using phonics, vocab, and custom DOK?

Pilot Usage

The same usage charts as Analytics, plus grade and subject mix. Answers: how is this pilot actually using Granted?

Survey

Survey Maker

Build a baseline, follow-up, or standalone survey with rating, number, or text questions. Answers: can we collect the next round of teacher feedback?

Feedback Review

Worksheet ratings by version source, the rating mix, and recent comments. Answers: what do teachers think of generated work?

Survey Results

Response counts for each survey and a breakdown per question. Answers: what did teachers tell us in this round?

Monitoring

Audit Log

Recent events, with failures highlighted, and a chart of which event types fail. Answers: what broke, and how often?
